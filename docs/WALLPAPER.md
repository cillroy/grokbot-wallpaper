# Живые обои для рабочего стола (Lively Wallpaper)

Офис ботов можно поставить как анимированные обои Windows. Нужна бесплатная программа Lively Wallpaper:
она показывает веб-страницу вместо обоев и пробрасывает на неё мышь, поэтому боты поворачиваются за курсором.

## Установка

1. Поставь **Lively Wallpaper** из Microsoft Store (бесплатно).
2. Запусти `./start.sh` на сервере. Последняя строка вывода: **«Ссылка для обоев: …»**. Скопируй её целиком, вместе с `?mode=wallpaper&key=…`. Ключ входа уже внутри, пароль вводить не нужно.
3. В Lively нажми **«Добавить обои»** (плюс в углу окна), вставь ссылку и подтверди. Обои сразу встанут на рабочий стол.
4. В настройках Lively включи **ввод мыши для обоев** (раздел настроек обоев, пункт про ввод: «Wallpaper input» → «Mouse»; название может чуть отличаться в твоей версии). Без этого боты не реагируют на курсор.

## Что на экране

Только офис и одна тихая строка в правом верхнем углу: «6 работают · 1 ждёт тебя». Панелей, карточек и ленты нет, масштаб и перетаскивание отключены, это фон. Обои рисуют не больше 30 кадров в секунду и не рисуют вообще, пока страница скрыта.

## Параметры ссылки

Дописывай после `?mode=wallpaper`, через `&`:

| Параметр | Что делает |
|---|---|
| `floor=<id>` | закрепить этаж (например `floor=x-content`). Без него берётся этаж, где больше всего ботов |
| `cycle=60` | каждые 60 секунд переезжать на следующий этаж на лифте (минимум 5) |
| `tags=1` | показывать над ботами подписи, кому нужна помощь |
| `theme=ranch` | тема Texas Hill Country (ранчо в Центральном Техасе). Без параметра — обычный офис. `theme=office` возвращает его. Выбор в меню Theme на дашборде запоминается в том же браузере |

Пример: `https://…/?mode=wallpaper&floor=x-content&cycle=90&key=…`

## Советы

- **Спрячь значки рабочего стола:** правый клик по рабочему столу → Вид → снять «Отображать значки рабочего стола». Иначе они лягут поверх офиса.
- **Ссылка меняется, если туннель перезапустился.** Адрес вида `*.trycloudflare.com` новый при каждом запуске туннеля. Тогда запусти `./start.sh` ещё раз, возьми свежую строку «Ссылка для обоев» и замени обои в Lively. Постоянная ссылка появится позже.
- **Ключ — это доступ к дашборду только на просмотр.** Не публикуй ссылку. Чтобы сменить ключ, удали `data/view-key.txt` и перезапусти сервер: старая ссылка перестанет открываться (уже выданные сессии живут до 30 дней).
- Если вместо офиса видишь окно с паролем, ключ в ссылке неверный: возьми ссылку из `./start.sh` заново.
- Для проверки в обычном браузере открой ту же ссылку. Время суток можно подменить: `&time=22:30`.
